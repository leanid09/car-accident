# Tesla Model Y rear collision — evidence package

Evidence and repair documentation for the August 7, 2026 rear collision at the Tesla Supercharger, 5795 Christie Avenue, Emeryville, CA. Tesla Insurance claim **CL-83-92MLUQ-5**.

**The report to show at the Tesla Collision Center is [`report/collision-report.md`](report/collision-report.md).**

## What's here

| Folder | Contents |
| --- | --- |
| `report/` | The collision damage report (summary, timeline, speed analysis, damage, requested inspections) |
| `videos/` | Raw Tesla dashcam exports (rear + side camera, with Tesla's gear/speed overlay burned in) and iPhone video of the in-car playback |
| `exhibits/dashcam-stills/` | Key frames from the footage: the approach, the contact at 0 MPH, the Kia sliding past |
| `exhibits/photos/` | Photo of the rear on the morning of drop-off (Oct 13, 2026) |
| `charts/` | Rendered figures used by the report: speed traces, site schematic, damage map, claim timeline |
| `data/` | Machine-readable data: telemetry speed trace, Kia speed estimates, evidence file index |
| `analysis/` | Independent frame-by-frame verification: extraction grids and method notes ([`analysis/ANALYSIS.md`](analysis/ANALYSIS.md)) |
| `sources/` | Published references cited by the report |

## Key finding

Tesla's own telemetry overlay, burned into the dashcam export, shows the Model Y reversing at no more than 4 MPH, braking to **0 MPH before contact**, and remaining stationary while the Kia Soul (estimated 13–16 MPH approach, 6–9 MPH at impact) struck and slid across its rear.
